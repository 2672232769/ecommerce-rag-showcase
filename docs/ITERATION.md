# 一次实际的问答改进

## 发现的问题

问题：“海风 T500 保温杯能放进微波炉吗？”

资料明确写了“禁止使用微波炉加热”，同时写有“未提供婴幼儿专用认证信息”。早期回答虽然答对了微波炉问题，却额外扩展到用户没有问的内容，并把“未提供认证信息”推成了“不建议用于婴幼儿场景”。后者超出了资料能够支持的结论。

该回答保留在 [完整会话记录](../snapshots/20261029/conversations.md) 的“商品问答与引用”会话中。
